# MCB WWW v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Nowa, redakcyjno-naukowa strona MCB UKSW (PL/EN) z czytelną ścieżką usługa → aparatura → ekspert, zbudowana od zera na treści przeniesionej z v1.

**Architecture:** Next.js App Router z segmentem `[locale]` (pl domyślny, en), wszystkie strony SSG. Treść w typowanej warstwie `content/` (port z v1) z powiązaniami po id; logika domenowa jako czyste funkcje testowane Vitestem. Jedyny endpoint dynamiczny: `/api/contact` + `/api/captcha`.

**Tech Stack:** Next.js 16, React 19, TypeScript 5, Tailwind CSS v4, `motion`, `resend`, `lucide-react`, Vitest, @playwright/test, Docker (standalone).

**Spec:** `docs/superpowers/specs/2026-10-15-mcb-v2-design.md`

**Źródło v1 (tylko do odczytu):** `/Users/krzysztofbojko/DATA/mcb-website` (dalej `V1`).

## Global Constraints

- Repo: `/Users/krzysztofbojko/DATA/mcbwww-v2`, branch `main`, remote `https://github.com/krzysztofbojko/mcbwww-v2.git`.
- Locales: `["pl", "en"]`, domyślny `pl`; `/` → przekierowanie 307 do `/pl`.
- Pola tłumaczalne: `type L = { pl: string; en?: string }`; brak `en` → fallback do `pl`.

## Review Focus

1. Usługa, której `contact` w v1 to „MCB UKSW” lub kilka osób („A, B”) → strona usługi pokazuje ogólny kontakt MCB albo wszystkich ekspertów, nigdy pustą sekcję. (Task 2: `resolveExperts` testy)
2. Wejście na `/en/...` dla treści bez tłumaczenia → strona renderuje polski tekst, nie `undefined` ani pusty nagłówek. (Task 3: `t()` fallback test)

5. Filtr aparatury bez wyników i link do formularza z `?temat=` spoza listy → komunikat „brak wyników” / domyślny temat, bez błędu. (Task 2 `filterEquipment`, Task 6 `resolveTopic`)
